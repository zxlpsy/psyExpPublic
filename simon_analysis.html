方法说明：数据清洗与分析流程（可写入 report）
  1. 数据格式：每试次一行共 9 列：block、一致性(文字)、颜色、一致性编码(1/2)、表格行、状态码(1=正确，2=按错，3=超时)、RT(ms)、触摸X/Y坐标。仅分析 block = test 的正式试次。
  2. 剔除错误与超时试次：RT 只统计状态码=1 的正确试次；按错与超时（RT=5000ms）试次剔除，单独汇总为正确率指标。
  3. 剔除极端 RT：剔除 <200ms 的预期反应与 >1500ms 的过长反应（热身走神试次）。
  4. 被试内、条件内 ±3SD 修剪：对每名被试每个条件，剔除偏离该条件均值 3 个标准差之外的试次。
  5. 统计：一致/不一致 RT = 清洗后条件均值；Simon effect = 不一致 RT − 一致 RT；组水平取各被试均值，并以配对样本 t 检验考察显著性，同时报告效应量 Cohen's dz、Simon effect 的 95% 置信区间、分条件错误率与分条件 RT 标准差；误差线为被试间 95% 置信区间。
  6. 分布分析：按 Simon 任务文献惯例补充 RT 分布直方图、箱线图与 delta plot（效应量随 RT 五分位 Vincentile 的变化），用于刻画效应随反应速度的动态变化。
结果解读：完整分析结论（载入数据后自动生成，随清洗参数与剔除开关实时更新）

载入数据并完成分析后，本段将基于当前设置（清洗参数、是否启用错误率剔除及阈值）实时生成"描述—推断—数据质量—综合结论"四层解读；修改上方任一参数、勾选或取消剔除开关后，本段会与 KPI 和所有图表同步更新。

提示：柱状图误差线为 95% CI（被试间）；各图数值与底部“结果解读”均基于上述清洗规则，参数与剔除开关在上方修改后，KPI、全部图表与解读文字实时同步更新。
